# Ordacy

Public website for Ordacy, built with React, Vite, TypeScript, React Router and Styled Components.

## Commands

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint
- `npm run typecheck` — run the TypeScript compiler

## Structure

- `src/app` — application root and router
- `src/components` — shared layout, navigation and common components
- `src/features` — page-level features
- `src/styles` — theme tokens and global styles
- `src/types` — shared type declarations
- `src/assets` — images, icons and local fonts as they are added

Plus Jakarta Sans is loaded from Google Fonts. The current ORDACY header wordmark is text-based and can be replaced without changing the layout.
